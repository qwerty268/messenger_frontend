# Руководство пользователя

Программная система **Patefon** — веб-мессенджер, предназначенный для обмена текстовыми сообщениями, медиафайлами, создания групповых чатов и каналов. Настоящее руководство описывает основные сценарии использования системы с точки зрения пользователя.

## 1. Начало работы

### 1.1 Регистрация в системе

Для начала работы необходимо зарегистрировать учётную запись. Страница регистрации представлена на рисунке А.1.

*[Место для скриншота: Рисунок А.1 – Страница регистрации]*

Для регистрации необходимо заполнить следующие поля:

- **Имя пользователя** — отображаемое имя, которое будут видеть другие участники;
- **Логин** — уникальный идентификатор для входа в систему;
- **Пароль** — секретная комбинация символов;
- **Повторите пароль** — подтверждение пароля для исключения ошибки ввода.

После заполнения всех полей необходимо нажать кнопку **«Создать аккаунт»**. Если пароли не совпадают или введённые данные не соответствуют требованиям, система отобразит сообщение об ошибке под соответствующим полем.

Если у пользователя уже есть учётная запись, он может перейти на страницу входа по ссылке **«Уже есть аккаунт? Войти»**.

### 1.2 Авторизация в системе

Страница авторизации представлена на рисунке А.2.

*[Место для скриншота: Рисунок А.2 – Страница авторизации]*

Для входа в систему необходимо:

1. Ввести **логин** в соответствующее поле;
2. Ввести **пароль**;
3. Нажать кнопку **«Войти»**.

При вводе пароля доступна кнопка переключения видимости символов (иконка глаза), позволяющая проверить правильность ввода.

Если введены неверные или несуществующие учётные данные, система отобразит сообщение об ошибке. После успешной авторизации пользователь попадает на главный экран мессенджера.

## 2. Главный экран

После успешной авторизации пользователь попадает на главный экран системы, представленный на рисунке А.3.

*[Место для скриншота: Рисунок А.3 – Главный экран мессенджера]*

Главный экран разделён на три основные области:

1. **Левая панель (список чатов)** — отображает перечень всех доступных чатов, групп и каналов;
2. **Центральная область** — рабочая область для просмотра и отправки сообщений в выбранном чате;
3. **Правая панель (информация о чате)** — отображает информацию о текущем собеседнике, группе или канале.

В верхней части интерфейса расположена навигационная панель с кнопками:

- **Домой (🏠)** — возврат к списку чатов;
- **Контакты (👤)** — открытие списка контактов;
- **Настройки (⚙️)** — открытие профиля пользователя;
- **Аватар пользователя** — также открывает профиль.

### 2.1 Профиль пользователя

Экран профиля представлен на рисунке А.4.

*[Место для скриншота: Рисунок А.4 – Профиль пользователя]*

В профиле пользователь может:

- Изменить **аватар** — нажать на изображение аватара и выбрать файл с устройства;
- Указать **отображаемое имя**;
- Указать **дату рождения** (опционально);
- Добавить **описание профиля** (опционально).

Для сохранения изменений необходимо нажать кнопку подтверждения (✓). Для выхода из учётной записи предназначена кнопка с изображением двери в правом верхнем углу.

## 3. Работа с чатами

### 3.1 Список чатов

Список чатов отображается в левой части главного экрана. Для каждого чата показывается:

- Аватар чата;
- Название чата или имя собеседника;
- Последнее сообщение;
- Время последнего сообщения.

Для поиска по чатам предусмотрена строка поиска в верхней части списка. При вводе текста система выполняет поиск как по названиям ваших чатов, так и глобальный поиск по всем пользователям системы.

В нижней части списка расположена кнопка **«+»** для создания нового чата. При нажатии открывается меню с тремя вариантами:

- **Создать личный чат**;
- **Создать группу**;
- **Создать канал**.

### 3.2 Личный чат

Для начала общения с другим пользователем необходимо создать личный чат. После выбора опции **«Создать личный чат»** откроется список контактов, где нужно выбрать собеседника. Экран личного чата представлен на рисунке А.5.

*[Место для скриншота: Рисунок А.5 – Личный чат]*

### 3.3 Отправка сообщений

В нижней части окна чата расположена панель ввода сообщения, содержащая:

- **Поле ввода текста** — для набора сообщения (до 1000 символов);
- **Кнопка вложений (📎)** — открывает меню выбора вложений;
- **Кнопка эмодзи (😊)** — открывает панель выбора эмодзи и стикеров;
- **Кнопка отправки (➤)** — отправляет сообщение.

**Вложения.** При нажатии кнопки вложений пользователь может выбрать:

- **Фото** — изображение в форматах WEBP, GIF, JPEG, PNG;
- **Файл** — произвольный файл.

Выбранные вложения отображаются в миниатюрах над полем ввода. Можно прикрепить несколько файлов одновременно.

**Эмодзи и стикеры.** При нажатии кнопки эмодзи открывается панель с двумя вкладками:

- **Эмодзи** — выбор стандартных эмодзи-символов;
- **Стикеры** — выбор стикеров из доступных наборов.

### 3.4 Контекстное меню сообщения

При клике правой кнопкой мыши по сообщению открывается контекстное меню, представленное на рисунке А.6.

*[Место для скриншота: Рисунок А.6 – Контекстное меню сообщения]*

Доступные действия:

- **Ветка** — открыть обсуждение сообщения в виде ветки (доступно в группах и каналах);
- **Изменить** — отредактировать текст отправленного сообщения (доступно только для своих сообщений);
- **Удалить** — удалить сообщение (доступно только для своих сообщений).

После отправки сообщения рядом с отметкой времени отображается пометка «изменено», если сообщение было отредактировано.

## 4. Групповые чаты

### 4.1 Создание группы

Для создания группы необходимо выбрать опцию **«Создать группу»** в меню добавления чата. Экран создания группы представлен на рисунке А.7.

*[Место для скриншота: Рисунок А.7 – Создание группы]*

Пользователю необходимо:

1. Задать **название группы**;
2. При необходимости изменить **аватар группы**;
3. Выбрать **участников** из списка контактов;
4. Нажать кнопку подтверждения (✓) для создания.

### 4.2 Информация о группе

Экран информации о группе представлен на рисунке А.8.

*[Место для скриншота: Рисунок А.8 – Информация о группе]*

В правой панели отображается:

- Аватар и название группы;
- Количество участников;
- Переключатель **уведомлений** — позволяет включить или отключить уведомления от группы;
- Список **участников** (доступна прокрутка);
- **Фото** — общие фотографии, отправленные в чат;
- **Файлы** — общие файлы, отправленные в чат.

**Для владельца группы** доступна кнопка редактирования группы (иконка карандаша) рядом с аватаром, позволяющая изменить название и аватар группы.

В нижней части панели расположена кнопка:

- **«Удалить группу»** — для владельца группы;
- **«Выйти из группы»** — для остальных участников.

### 4.3 Приглашение участников

Владелец или администратор группы может пригласить нового участника, нажав кнопку **«+ Пригласить»** в разделе участников. Откроется список контактов для выбора.

## 5. Каналы

### 5.1 Создание канала

Для создания канала необходимо выбрать опцию **«Создать канал»** в меню добавления чата. Экран создания канала представлен на рисунке А.9.

*[Место для скриншота: Рисунок А.9 – Создание канала]*

Пользователю необходимо:

1. Задать **название канала**;
2. При необходимости изменить **аватар канала**;
3. Нажать кнопку подтверждения (✓).

### 5.2 Подписка на канал

Если пользователь не является участником канала, в окне чата отображается кнопка **«Подписаться»**. После нажатия пользователь становится подписчиком канала и может просматривать его публикации.

### 5.3 Публикация в канале

Отправлять сообщения в канале могут только **владелец** и **администраторы** канала. Для остальных подписчиков панель ввода сообщений не отображается.

Экран информации о канале аналогичен экрану группы, за исключением того, что в канале нет списка участников. Владелец может **удалить канал**, администратор — **выйти из канала**.

## 6. Ветки обсуждений

В групповых чатах и каналах доступна функция **веток** для обсуждения отдельных сообщений. Для создания ветки необходимо:

1. Нажать правой кнопкой мыши по сообщению;
2. Выбрать пункт **«Ветка»**;
3. В правой части экрана откроется панель обсуждения с выбранным сообщением;
4. Владелец или администратор может нажать **«Начать ветку»** для включения режима обсуждения.

Экран ветки представлен на рисунке А.10.

*[Место для скриншота: Рисунок А.10 – Ветка обсуждения]*

В панели ветки доступны:

- Поле поиска по сообщениям ветки;
- Текстовое поле для отправки сообщений;
- Кнопка отправки сообщения.

Для закрытия ветки необходимо нажать кнопку закрытия (✕) в заголовке панели.

## 7. Контакты

### 7.1 Список контактов

Экран контактов представлен на рисунке А.11.

*[Место для скриншота: Рисунок А.11 – Список контактов]*

Для перехода к контактам необходимо нажать кнопку **контактов (👤)** на верхней панели. В левой части экрана отобразится список контактов пользователя.

Для поиска контактов доступна строка поиска, которая ищет как среди ваших контактов, так и глобально по всем пользователям системы.

### 7.2 Добавление контакта

Для добавления нового контакта необходимо нажать кнопку **«+»** в нижней части списка контактов. Откроется форма добавления контакта, представленная на рисунке А.12.

*[Место для скриншота: Рисунок А.12 – Добавление контакта]*

Необходимо ввести **логин** существующего пользователя и нажать кнопку подтверждения. Если пользователь с указанным логином найден, он будет добавлен в список контактов. Если такого пользователя не существует, система отобразит сообщение об ошибке.

## 8. Управление чатами

### 8.1 Удаление чата

Для удаления личного чата, выхода из группы или канала необходимо:

1. Открыть соответствующий чат;
2. В правой информационной панели нажать кнопку **«Удалить чат»**, **«Выйти из группы»** или **«Удалить группу»** (в зависимости от типа чата и прав пользователя).

### 8.2 Редактирование группы

Владелец группы может изменить её название и аватар. Для этого необходимо:

1. Открыть группу;
2. В правой панели нажать иконку карандаша рядом с аватаром;
3. Внести необходимые изменения;
4. Нажать кнопку подтверждения (✓).

### 8.3 Поиск сообщений

В каждом чате доступен поиск по сообщениям. Для этого необходимо нажать кнопку поиска (🔍) в заголовке чата. Откроется строка поиска, при вводе текста система отобразит список найденных сообщений.

## 9. Уведомления

Система отображает уведомления о новых сообщениях. Для каждого чата можно индивидуально настроить получение уведомлений с помощью переключателя в информационной панели чата.

## 10. Выход из системы

Для завершения пользовательской сессии необходимо:

1. Открыть **профиль пользователя** (нажав на аватар или кнопку настроек);
2. Нажать кнопку **выхода** (иконка двери) в правом верхнем углу.

После этого система завершает текущий сеанс работы и возвращает пользователя к экрану авторизации.
